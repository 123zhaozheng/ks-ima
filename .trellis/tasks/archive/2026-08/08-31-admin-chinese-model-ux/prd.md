# 控制台全中文化、模型一键配置与 UX 修复

## Goal

把管理控制台与前台残留的"工程师腔"彻底改成中文、苹果风、新手友好的界面：模型配置支持 OpenAI 兼容网关一键拉取模型（名称/图标/能力/维度自动填充），删除全部多语言代码（仅保留中文），修复知识库切换与分享入口问题，审计页全中文化。

## Requirements

- R1 多语言代码全部删除：`i18n-pro`、`i18n/`、`i18nrc.ts`、`src/utils/i18n.ts`、语言切换器全部移除；所有 `t('X')` 替换为 zh-CN.json 中对应中文（缺失的自行翻译成自然中文）；Quasar lang 固定 `zh-CN`。不保留任何 en-US/zh-TW 逻辑。
- R2 模型配置简化（管理台「模型」页重写）：
  - 只要网关实现 OpenAI 兼容格式（base URL + API 密钥）即可接入；参考 one-api/new-api 的渠道模型管理思路。
  - 一键拉取：调用后端已有 `POST /api/v1/admin/model-gateways/{id}/discover`（走 `/v1/models`），弹窗勾选模型一键导入；自动识别能力（对话/向量化/重排序）、自动填充已知向量维度、自动识别厂商并显示真实 logo。
  - 厂商 logo 从公网爬取（@lobehub/icons-static-svg 等开源图标包），下载后内置到 `src/assets/model-logos/` 随仓库打包，运行时不依赖外网。
  - 术语中文化：网关→服务商，capability→能力（对话/向量化/重排序），工作流配置→场景配置（知识库问答/标题生成/摘要/向量化/重排序，每项附一句人话说明），分配与影响→知识库分配（影响提示用人话：「切换后 N 个索引需要重建」）。
  - 场景配置用结构化表单（选择已启用模型、topK 等），原始 JSON 收进「高级」折叠区。
- R3 审计页中文化：action/reason/result 全部映射为中文（映射表需覆盖后端 `_audit` 写入的所有 action 码，grep 后端穷举），未知码兜底显示原码；时间用中文友好格式；提供「动作类型/结果」筛选。
- R4 知识库切换与分享修复：
  - 左上角切换器选择知识库后立即（同步）更新名称，不再等异步详情、不再闪「未选择知识库」。
  - `switchKb` 不再强制跳回 `/`，停留在当前页。
  - 分享入口可见：`/kb` 工具栏放带文字的「分享」按钮（owner 可见），切换器菜单当前知识库条目下增加「管理与分享」入口；修复 `kbStore.isOwner`（详情接口不返回 `owned`，改用成员列表中的 role）。
- R5 UI 排布美化：重写的页面统一苹果风——大留白、圆角卡片、细边框、少而克制的按钮、中文文案自然口语化，禁止整屏英文术语。
