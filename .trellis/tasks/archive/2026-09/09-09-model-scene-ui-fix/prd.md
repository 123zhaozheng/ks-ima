# 模型配置页面简化与中文修复

## 背景
当前模型配置页面存在以下问题：
1. 「场景配置」标签页概念复杂，需要「新建草稿」「验证」「发布」三个步骤
2. 「知识库分配」标签页多余（真正的模型绑定在知识库详情页）
3. 多处英文暴露：`add refresh`、`archive delete`、`Model`、`Capability` 等表头

## 目标
1. 去掉「新建草稿」概念，每个场景直接提供「选择模型」下拉框 + 保存
2. 删除「知识库分配」标签页（因为真正的分配在知识库详情页做）
3. 将所有表头、按钮、提示改为中文

## 验收标准
- 场景配置卡片只显示场景名称、描述、当前使用的模型、保存按钮
- 每个场景的下拉框只展示已启用的对应能力模型
- 知识库列表的 `Archive` / `Delete` / `Add` / `Refresh` 全部改为中文
